# Визуальная основа панели Rele

Полный концепт главного экрана создан 18 октября 2026. Изображение служит ориентиром; все элементы интерфейса реализуются в HTML/CSS, демонстрационные разговоры доступны только в тестовых fixtures.

## Система

- Графитовый фон `#101416`, боковая панель `#151a1e`, поверхность `#181e22`, границы `#2b353c`.
- Основной текст `#eef2f5`, вторичный `#a5b0ba`, бирюзовый акцент `#56ded4`. Семантические предупреждения янтарные, ошибки красные.
- Segoe UI / системный sans-serif; основная типографика 15 px, заголовок 42 px, компактные подписи 13 px. На небольшом ноутбуке заголовок 36 px, на телефоне 30 px.
- Боковая навигация 248 px; контент с отступом 40 px; таблица с разделителями, строки от 96 px; скругления 8 px.
- SVG-иконки с обводкой 1.8 px. Названия пунктов: «Связи», «Доступ», «Очередь», «Доставка», «Подключения», «Codex».
- Кнопки одного семейства: бирюзовая основная, контурная вторичная, текстовая, опасное действие. Видимый фокус, одинаковые состояния busy и disabled.

## Экран и обязательные расширения

Главный экран «Связи» ориентирован на входной источник. Две доступные с клавиатуры вкладки Telegram/Slack, поиск по группе/теме/назначению и таблица «Группа / чат — Тема / обсуждение — Разговор Codex». Все обнаруженные источники видимы, включая несвязанные/недоступные и лички. Dropdown выбирает существующий native тред или открывает компактный выбор cwd для создания при первом разрешённом запросе. «Сведения» сохраняют локальное имя, общий pause/resume и Slack journal. Права и AutoLinks находятся в отдельном «Доступе»: off/mention/all + human-only DM drawer. Нет группового снятия паузы при выключении одного входа.

На телефоне навигация прокручивается внутри своей области, строки становятся размеченными карточками, поиск занимает отдельную строку toolbar. Dialog сохраняет focus/keyboard Escape. Незавершённые принятые запросы блокируют обычное переназначение; uncertain/failed auto intents используют явный recovery drawer вместо скрытого переноса старых событий. Существующий графитовый стиль, цвета, типографика и компоненты сохранены.

Обоснованные отклонения от изображения: пустые состояния вместо вымышленных данных при первом запуске; flat background без сгенерированной фактуры; состояние соединения и выход из панели внизу меню; функциональные сообщения об ошибках, запросы подтверждения, загрузка, формы и диагностика. Без фиктивных метрик и гарантий совместимости Desktop.

## Проверка реализации

Концепт и последние скриншоты сопоставлены через просмотр изображений при размере desktop 1536 × 1024. Мобильная версия проверена при 390 × 844. Основная реализация соответствует выбранной геометрии и визуальной системе; растровый скриншот не используется как интерфейс.

| Проверка            | Результат                                                                                                                                                 |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Компоновка          | Сохранены боковая навигация, заголовок с основным действием, поиск, единая таблица и нижние шаги настройки.                                               |
| Плотность и отступы | Три строки таблицы помещаются в первый экран. Небольшое уплотнение шрифтов и боковой панели относительно изображения закреплено в токенах выше.           |
| Текст и действия    | Названия разделов и основное описание совпадают; «Связок: N» вместо склоняемого статичного примера. Добавлены необходимые «Выйти» и состояние соединения. |
| Цвета               | Графитовая поверхность и один бирюзовый акцент; намеренно убрана сгенерированная фактура фона.                                                            |
| Иконки              | Сохранены назначение, контурный характер навигации и знаки Telegram/Slack в строках.                                                                      |
| Поля и диалоги      | Одинаковые поля и кнопки; начальный фокус на имени связки, Escape закрывает диалог и возвращает фокус на действие открытия.                               |
| Мобильная версия    | Размеченные строки таблицы, все названия и действия доступны, горизонтального переполнения страницы нет.                                                  |

Browser extension в рабочей сессии был недоступен; cloud browser не достиг локального сервера. Проверка выполнена локальным Playwright в официальном Chrome. Девять E2E-сценариев охватывают авторизацию и очистку fragment, атомарное создание связки, явный выбор отправителей, поиск/переименование/паузу/отвязку, локальные имена чатов с возвратом исходного имени, отмену и сверку запроса, продолжение ранее принятой очереди, ответы на уточнения, ограничения повторной доставки, write-only секреты и восстановление соединения. Mock API живёт только в tests/e2e. Дополнительно просмотрены формы локального имени и очередь при 1536 × 1024 и 390 × 844; сохранение имени доступно после прокрутки мобильного диалога, горизонтального переполнения и ошибок JavaScript нет.

Самостоятельный `scripts/smoke-ui.mjs` проверяет собранный интерфейс через настоящий HTTP-сервер без fixture API: выполнение JavaScript при production CSP, Bearer в запросах панели, пустое начальное состояние, сохранение скрытого секрета отключённого подключения и сохранность конфигурации после перезапуска. Сценарий использует временный каталог, несуществующий исполняемый файл Codex и вымышленные данные; запуск в Linux прошёл. Проверка Windows и настоящих подключений проводится отдельно.


## Проверка нового потока 21.10.2026

Синтетический QA: Chromium через установленный Playwright, desktop1536×1024 и mobile390×844, корректные URL/title, no framework overlay/console errors/horizontal page overflow. Проверены общая цель Codex у разных платформ, unbound DM, human-only ACL, source drawer Escape. Полные сценарии также покрывают реестр новых Slack DM, pagination/race каталога, темы Telegram, alias Enter/reset, ошибки сохранения, offline off/unlink, права отдельно от маршрута. Это проверка кода и fixture UI, не реальной доставки Slack/Telegram/Desktop.
