# Rele

Локальный шлюз между Telegram, Slack и общими разговорами Codex.

## Целевой сценарий

- Windows: Rele, codex app-server и Codex Desktop на одном ПК.
- Ubuntu Server: Rele, codex app-server и Codex CLI на одном сервере.
- Одна связка: один тред Codex, максимум один разговор Telegram и один тред Slack.
- Общий контекст Codex; каждый ответ возвращается в источник своего запроса.
- Веб-панель показывает связи по названиям.

WSL и отдельный компонент Rele Node исключены из первого релиза.

## Состояние

Идёт разработка первого выпуска. Совместный активный runtime с Windows Desktop должен пройти отдельную реальную проверку. До этого поддержка Desktop не считается подтверждённой.

Архитектура и план переносятся в `docs/`. Первый этап — проверка атомарной очереди Codex и безопасного подключения к существующему серверу, затем локальное ядро, оба мессенджера, веб-панель, восстановление и пакеты для обеих ОС.
