# Rele 0.1.0-rc.19

При обновлении Rele больше не требуется вручную сохранять «Общий Codex» и подключать обычный запуск Desktop. Выбранная задача установщика подготавливает общий Codex в прежнем профиле и проверяет ранний обмен Desktop до записи принадлежащих Rele параметров запуска. Если Desktop был открыт до установки, после завершения его задач нужен один полный Quit и обычный запуск. Файлы Desktop не изменяются.

Автоматический переход охватывает старый недоступный plain WebSocket на loopback без ключа и стандартный локальный managed/proxy без явного executable или socket. Работающий старый endpoint, удалённый или защищённый отдельным ключом сервер, нестандартный socket и несовпадение профиля блокируют переход. Происхождение старого порта не угадывается: переход выполняется как выбранная пользователем задача установщика. Чужие параметры Desktop не заменяются.

Во время подготовки удерживается тот же lock каталога данных, который использует gateway. SQLite читается без миграции и записи. Активный запрос, native submission, ожидающее подтверждение, незавершённое автосоздание или неопределённая синхронизация контекста блокируют смену подключения. Неотправленная очередь, связки и pending-контекст сохраняются в том же профиле. Перед атомарным сохранением shared policy исходный зашифрованный config записывается в отдельный backup, даже если SQLite ещё не создана. Авторизация, история, config.toml и ID native разговоров не копируются и не изменяются.

Выбор интеграции хранится отдельно от результата её применения. Временный отказ запуска оставляет выбранный shared policy и pending intent; обычное восстановление Codex продолжается. При подтверждённом shared-соединении с проверенной версией Codex Rele один раз за свой запуск повторяет установку ожидающей интеграции Desktop. До успешной проверки hook не включается. Явное отключение из панели сохраняется при следующем обновлении; параметры /TASKS и /MERGETASKS установщика имеют приоритет. Чтение статуса панели ничего не запускает.

В точный список версий добавлен backend `0.163.0-alpha.11.2` из обновлённой поставки Desktop. Прежние `0.163.0`, `0.163.0-alpha.10.2` и `0.163.0-alpha.11` сохраняются. Разрешение не распространяется на другие alpha, суффиксы или будущие версии.

Проверки конкретного commit и пакетов приводятся в описании GitHub release. Полная пользовательская приёмка живых Slack/Telegram, телефона, reboot и длительной работы остаётся в [ACCEPTANCE.md](ACCEPTANCE.md). Windows RC пока без подписи издателя.
