# Rele 0.1.0-rc.11

Исправлен каталог Slack, в котором вместо личных чатов показывались только каналы. `users.conversations` теперь получает form-параметры, включая типы разговоров и cursor. Ранее Slack мог вернуть HTTP200/ok, проигнорировав JSON-параметры и применив тип public_channel по умолчанию.

Каталог учитывает read scopes, выданные bot token: отсутствие `mpim:read` для групповых личных чатов не блокирует обычные DM с `im:read`. Панель показывает доступные чаты и предупреждение о недостающих правах. Проверка членства остаётся строгой: известного ID или старого сообщения недостаточно для разрешения доступа.

Доступный личный чат снова появляется в каталоге и восстанавливает сохранённую отметку доступности после подтверждения Slack. Он называется именем собеседника со стороны бота. В «Подключения → Новые разговоры из мессенджера» выберите этот чат, рабочую папку Codex, разрешённого человека и включите правило. Затем отправьте новое сообщение; ответ доставляется в его Slack-тред. Старые пропущенные сообщения автоматически не запускаются.

Настройки, разрешения Slack, данные Codex и SQLite v5 не мигрируются. Установку выполняет пользователь. Живой запрос после обновления и настройки правила ещё требует проверки; source-level и fixture проверки не заменяют фактическую доставку.
