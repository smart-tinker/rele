# 0.1.1-rc.2 — автосоздание на пустом профиле Codex

Исправляет [#49](https://github.com/smart-tinker/rele/issues/49), найденную при
приёмке RC.1. Подключённый Codex из проверенной allowlist позволяет настроить
автосоздание чата для конкретного источника, даже если на новом профиле ещё нет
обычных чатов и поддержка очереди пока не подтверждена.

Проверка очереди перед отправкой остаётся обязательной. Engine сначала создаёт
и материализует чат по принятому источнику; настройка маршрута сама не создаёт
фиктивного чата и не отправляет модельных запросов. Отключённый/непроверенный
runtime и недопустимая рабочая папка по-прежнему отвергаются.

Включает все исправления [RC.1](0.1.1-rc.1.md). Его опубликованные assets/tag
сохраняются. Сборка: Linux на linux-build-host, Windows на windows-test-host. Приёмка готовых
пакетов: только windows-test-host (Windows) и linux-test-host (Linux), без dev-suite на этом этапе.
DEB-приёмка linux-test-host продолжается после завершения её активной задачи.

Это prerelease. Issues остаются открытыми до принятия критериев; stable и
обновление остальных машин в текущий цикл не входят.
