# Rele 0.1.0-rc.9

Одна связка теперь объединяет несколько Telegram и Slack обсуждений с одним Codex-тредом. Каждый запрос возвращает ответ, уточнение, подтверждение и управление в свой источник. Очередь общая; соседние binding IDs изменяются независимо.

В «Подключения» добавлены правила автоматического создания. Выберите доступный чат и абсолютный рабочий каталог Codex, задайте доступ и включите правило. В личных сообщениях допускаются только выбранные люди. Разрешённые группы принимают все свежие сообщения участников, включая агентов; при галочке «только по упоминанию» нужен свежий вызов бота. Ограничения видимости событий самих Telegram/Slack сохраняются.

Новое обсуждение без связки получает новый native Codex-тред и связку. Свежие принятые события сохраняются до ACK мессенджера, первые параллельные сообщения объединяются в одно создание. Существующая связка, её пауза или занятость Codex не создают копий. История не выполняется задним числом. Отключение правила сохраняет созданные связки.

При потере ответа на `thread/start` Rele не повторяет создание. Журнал показывает «Неопределённо»; проверьте список Codex и вручную свяжите существующий разговор с исходным обсуждением. Если native ID уже получен, он сохраняется. Перед освобождением нового пустого треда Rele задаёт ему название исходного обсуждения: штатная запись метаданных сохраняет native историю на диск без запуска модели. Изменившиеся подключения или правила не разрешают незаметно создать тред в другом профиле.

Исправлена воспроизводимая гонка ложного «Выполнение запроса остановлено в Codex»: промежуточный history interrupted без подтверждённого времени завершения больше не принимается за финальный Stop. Настоящая подтверждённая отмена остаётся отменой. Это исправление исходников; конкретная причина скриншота на рабочем Windows отдельно не диагностировалась.

SQLite мигрирует v4 → v5 с сохранением существующих ID, ACL, истории и доставок. Сделайте штатный backup перед обновлением. Старые версии не открывают v5; для отката нужна совместимая копия до миграции и сверка новых событий. Проверяемые Codex: 0.163.0 и 0.163.0-alpha.10.2. Ubuntu Server без Desktop и общий app-server с Desktop сохраняются. Обновление не переключает Desktop и не меняет настройки Slack app.

Живая приёмка на рабочем Windows, native Stop, spinner в Activity/Threads и управление с телефона остаются отдельными проверками. Установку выполняет пользователь.
