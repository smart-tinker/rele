# Rele 0.1.0-rc.14

## Достаточно установленного Codex Desktop

На Windows первый запуск «Общего Codex» больше не требует отдельной установки CLI. Rele находит локальный Desktop, проверяет поддерживаемую версию его backend и наличие всех обязательных компонентов одной поставки. Из них создаётся неизменяемый локальный пакет в каталоге данных Rele. Затем штатный Codex запускает общий daemon в исходном профиле.

Rele ничего не скачивает для этой подготовки и не изменяет установленный Desktop. Один скопированный `codex.exe` без остальных компонентов не подходит. Неполная поставка, изменение файлов во время подготовки, повреждённый кэш или неподдерживаемая версия блокируют запуск с пояснением. Исполняемые файлы из разных установок не смешиваются. При уже работающем общем daemon его процесс и задачи сохраняются.

Native Codex сам размещает рабочий пакет внутри `CODEX_HOME`; Rele не записывает его selection, PID или socket вручную. Auth, настройки, история и ID разговоров остаются в исходном профиле. Обновление Desktop или Rele не заменяет уже работающий общий сервер. Штатная политика updater Codex сохраняется.

## Как подключиться

1. Установите Rele под тем же пользователем Windows, что и Desktop.
2. В разделе «Codex» выберите «Общий Codex» и «Находить Codex автоматически». Для нестандартного профиля укажите прежний `CODEX_HOME`.
3. Если Desktop уже работал со своим приватным сервером, один раз полностью выйдите из приложения. Rele сам его не закрывает.
4. Откройте «Codex Desktop (общий с Rele)» из меню Пуск. Launcher предпочитает основной `ChatGPT.exe` новой поставки и поддерживает прежний `Codex.exe`.

Старые явные managed/proxy/WebSocket настройки сохраняются: переход выполняется явно при отсутствии активных запросов. Оба клиента используют один native daemon и исходные разговоры. Подтверждения, уточнения и отмена запроса Rele доступны из его исходного мессенджера. Интерактивный CLI запускается через `rele codex` / `rele-codex`; `codex exec` общий `--remote` не поддерживает.

На Ubuntu Server остаётся установленный Codex CLI, без Desktop. Независимый systemd starter/timer и восстановление после рестартов сохраняются. Пакеты Rele включают Node.js; новых зависимостей и миграции SQLite нет.

## Проверка и ограничения

Проверяются три точные версии backend: `0.163.0`, `0.163.0-alpha.10.2`, `0.163.0-alpha.11`. Новая непроверенная версия не получает разрешения на запись, очередь сохраняется.

Приёмка RC включает реальные Windows/Ubuntu пакеты, native lifecycle, исходные thread/request IDs, восстановление, SID/ACL/DPAPI и installer/recovery. Для Windows отдельно проверяется backend из официального подписанного Desktop MSIX OpenAI.Codex `26.1016.6573.0` (`0.163.0-alpha.11`) без npm CLI. Протокольные сценарии используют изолированные профили и тестовый provider; они не считаются запуском настоящего GUI или приёмкой реальных мессенджеров.

Реальные Desktop GUI, телефонные подтверждения и reboot остаются отдельной пользовательской приёмкой. Stable не публикуется. Рабочий ПК при подготовке этого выпуска не используется.
