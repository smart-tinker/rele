# Rele 0.1.0-rc.20

Windows Desktop подключается к общему native app-server напрямую по loopback WebSocket. Установщик меняет только принадлежащий Rele адрес `CODEX_APP_SERVER_WS_URL`; прежние собственные CLI_PATH/FORCE_CLI восстанавливаются по сохранённым значениям. Адаптер между Desktop и сервером, отдельный CLI и копирование профиля не нужны. После первого подключения уже открытый private Desktop требует одного полного Quit и обычного запуска.

Независимая задача текущего Windows-пользователя запускает backend установленного Desktop/CLI и восстанавливает его после отказа. Маленький immutable ProcessHost остаётся вне обновляемой папки Rele. Контроллер проверяет SID, executable/hash, время рождения процесса, PID владельца порта и исходный профиль. Обновление Rele сохраняет живой сервер; удаление восстанавливает собственный адрес и отменяет будущий автозапуск, сохраняя текущих клиентов. Ubuntu использует прежний штатный daemon/UDS: обычная команда `codex` не подменяется.

После Stop Rele автоматически продолжает единственную подтверждённую собственную запись native-очереди. Чужая или смешанная очередь остаётся защищённой от запуска. Для отменённой собственной shell-команды проверяется завершение native terminal и дочернего процесса до освобождения запроса и запуска следующего. Потерянный ответ управления сверяется; после потери исходного connection/Engine epoch неподтверждённый cleanup остаётся неопределённым, PID вслепую не повторяется.

Windows адрес-only Desktop не передаёт Bearer. Поэтому локальный RC слушает только `127.0.0.1` без токена и доступен другим локальным процессам и пользователям машины. Порт нельзя открывать в сеть. Native WebSocket upstream остаётся экспериментальным; native terminate не предоставляет atomic expected-item/turn CAS.

Результаты для точного commit и пакетов приводятся в GitHub release. Реальные Slack/Telegram, управление с телефона, reboot и длительная эксплуатация остаются отдельной пользовательской приёмкой из [ACCEPTANCE.md](ACCEPTANCE.md). Проверки с synthetic provider/source не выдаются за эту приёмку. Windows RC без подписи издателя.
