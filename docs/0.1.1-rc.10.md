# Rele 0.1.1-rc.10 — чтение квитанций native-журналов

Refs [#70](https://github.com/smart-tinker/rele/issues/70).

После подтверждённого заголовка сессии reader пропускает завершённую строку,
состоящую только из нулевых байтов. Native Codex также пропускает такую строку.
Это позволяет продолжить проверку реальных квитанций в остальной истории.
Сама нулевая строка не подтверждает ни сообщение, ни принадлежность сессии.

Проверки пути, ID сессии, UTF-8, размера строки, незавершённого хвоста,
точного ID и текста сообщения сохраняются. Другой повреждённый JSON по-прежнему
останавливает сверку. Native-журналы не переписываются, запросы не повторяются.
Сжатием контекста управляет Codex; отдельная политика контекста в Rele не добавлена.

Критерии: искусственная регрессия до/после исправления, Windows/Linux gates,
проверка готовых пакетов на windows-test-host/linux-test-host и отдельная сверка восстановления
квитанций. Merge и публикация RC не заменяют живую приёмку или принятие stable.
