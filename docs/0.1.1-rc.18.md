# 0.1.1-rc.18 — Slack: изображения, ответы и Auto-review

- [#84](https://github.com/smart-tinker/rele/issues/84): изображения из новых разрешённых запросов Slack передаются в тот же ход Codex, в том числе без подписи. В пассивной истории сохраняются метаданные вложений.
- [#87](https://github.com/smart-tinker/rele/issues/87): отдельные части ответа с точным маркером `NOREPLY` исключаются до объединения; полезный текст сохраняется.
- [#89](https://github.com/smart-tinker/rele/issues/89): проверенный владелец может открыть в Slack приватную форму с командой, отклонённой Auto-review, и передать решение Codex. Rele не повторяет команду; новую попытку проверяет Codex. Функция выключена по умолчанию и настраивается [для одного треда](https://github.com/smart-tinker/rele/blob/v0.1.1-rc.18/docs/CHANNELS.md#подтверждение-отказа-auto-review) на Codex `0.166.0-alpha.6`.

Этот кандидат не меняет разрешения на приложения Codex Desktop ([#83](https://github.com/smart-tinker/rele/issues/83)) и не переписывает старую историю ([#86](https://github.com/smart-tinker/rele/issues/86)). Очередь обновляет схему базы до v9. Для отката на RC16 используйте резервную копию v8, сделанную до обновления. Не переотправляйте запросы с неизвестным исходом.
