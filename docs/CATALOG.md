# Каталог разговоров и создание связки

Rele показывает варианты по названиям. Вы выбираете один разговор Codex, один разговор или тему Telegram и один тред Slack. Telegram или Slack можно не подключать. Совпадение названий не требуется: после выбора связь хранится по постоянным идентификаторам.

## Начало

1. Откройте локальную панель Rele и раздел «Подключения».
2. Подключите существующий Codex app-server и нужные мессенджеры. [Настройка токенов](CHANNELS.md).
3. Перейдите в «Связки» → «Новая связка».
4. Введите понятное название связки и выберите разговоры.
5. Явно отметьте людей, которым разрешено отправлять задачи, и создайте связку.

Просмотр каталога, загрузка истории и выбор вариантов не запускают Codex. После сохранения отправьте новое сообщение от разрешённого участника. Ответ вернётся в тот разговор, откуда пришёл запрос, с контекстом выбранного треда Codex.

## Codex

Список загружается с подключённого локального app-server. Предлагаются обычные пользовательские разговоры CLI, Desktop и app-server, включая сохранённые exec-разговоры. Guardian, review, compact и другие служебные субагенты скрыты по типу и родительским метаданным; название само по себе ничего не исключает.

Первое открытие быстро читает индекс Codex. Если старого разговора нет, нажмите «Обновить разговоры»: полное перечитывание найдёт ещё не проиндексированные записи и может занять больше времени. Поиск учитывает название, рабочую папку и начало разговора. При одинаковых названиях ориентируйтесь на папку. Разговор, уже занятый другой связкой, нельзя выбрать повторно.

Фильтр архива позволяет увидеть архивные разговоры. Для создания связки сначала восстановите нужный разговор в Codex и обновите список Rele. Открытие каталога не восстанавливает, не возобновляет и не изменяет разговор.

На Windows это хранилище того профиля и runtime, к которому присоединился Rele. На Ubuntu Server используется локальный app-server с Codex CLI. Каталог не собирает историю со всех устройств аккаунта OpenAI.

## Slack

Сначала выберите канал, личный или групповой диалог, затем корневое сообщение обсуждения. Rele загружает список через bot token; новое сообщение в каждом треде для обнаружения не требуется.

У обсуждения показываются начало сообщения, название канала и дополнительные сведения. Сообщение без ответов тоже можно выбрать как начало будущего треда. Если нужного обсуждения нет на первой странице, загрузите следующие записи. Поиск ограничен уже загруженными вариантами.

После выбора обсуждения Rele загружает участников разговора по именам. Отметьте только нужных отправителей: загрузка списка никому автоматически не разрешает запуск Codex. Ранее разрешённые люди сохраняются при обновлении каталога.

В каталоге доступны разговоры, участником которых является бот. Для закрытого канала его нужно пригласить. Если Slack сообщает о недостающих scopes, установите приложение с актуальным [manifest](../integrations/slack-manifest.json). История зависит от её доступности в workspace. При ограничении частоты запросов подождите указанное Slack время и повторите загрузку.

## Telegram — только токен бота

Telegram Bot API не выдаёт полный список старых чатов и существующих тем. Поэтому панель показывает **обнаруженные чаты**, сохранённые Rele. Новые доступные боту сообщения и события участия обновляют этот каталог. Пользовательский Telegram-аккаунт подключать не нужно.

### Добавить группу

1. Добавьте бота Rele в нужную группу.
2. В форме связки нажмите «Выбрать группу в Telegram».
3. В открывшейся личке бота нажмите Start, если Telegram предлагает это действие, затем кнопку выбора группы.
4. Выберите группу во встроенном списке Telegram и вернитесь в Rele.
5. Обновите обнаруженные чаты. Выбранная группа появится по названию.

Rele проверяет, что бот имеет доступ к выбранной группе. Для группы с темами затем нужно выбрать конкретную тему. Выбор группы сам по себе не перечисляет все её старые темы.

### Добавить тему или личный чат

Панель предлагает короткую команду регистрации. Выполните её внутри нужной темы или личного чата, например:

```text
/rele_register Мониторинг
```

Название после пробела необязательно. Оно полезно для старой темы, название которой Telegram ещё не сообщал Rele. Команда сохраняет разговор и имя отправителя, но не передаётся Codex — в том числе в уже связанной теме. Затем обновите список в панели, выберите разговор и разрешите своего отправителя.

Для группы без тем целью связки служит группа целиком. Для группы с темами выберите тему. Известные недоступные разговоры остаются видимыми, но не предлагаются для новой связи; после возвращения бота в группу каталог обновится по новым событиям.

«Общая» тема тоже поддерживается: зарегистрируйте её командой внутри этой темы или отправьте доступное боту сообщение, затем выберите её в Rele. После обнаружения она становится доступна в поле «Разговор Telegram» выбранной группы; до этого одна запись группы ещё не позволяет связать её с Codex. Входящие обычные цепочки ответов не превращаются в новые темы. При обновлении со старой версии Rele не переносит существующую связь на другой адрес автоматически; при необходимости явно выберите обнаруженную «Общую» тему.

Основная команда регистрации — `/rele_register` с необязательным именем. При privacy mode короткая команда в группе может не дойти до нужного бота; в таком случае отправьте отдельным сообщением адресную форму с точным `@именем_бота`, показанную в панели. Для регистрации поддерживаются обе формы; для последующих произвольных запросов настройте нужный доступ бота к сообщениям группы. [Официальное описание privacy mode](https://core.telegram.org/bots/faq#what-messages-will-my-bot-get).

## Существующие связки

Откройте связку, чтобы изменить Telegram/Slack или разрешённых отправителей. Занятые другой связкой разговоры отмечены в списках. Локальное переименование меняет подпись в Rele и сохраняется при обновлении названия в мессенджере.

После смены токена разговоры прежнего бота не становятся разговорами нового. Сохранённая связка остаётся доступной для просмотра и отвязки; выберите новый доступный разговор, чтобы заменить подключение. Уже принятые запросы сохраняют свой исходный адрес доставки.

## Обновление с предыдущего кандидата

Перед первым запуском 0.1.0-rc.2 создайте резервную копию Rele. Каталог добавляет метаданные в схему SQLite v3; существующие связки, разрешения и история сохраняются. Для возврата к rc.1 понадобится копия до обновления. [Порядок обновления и восстановления](OPERATIONS.md#обновление).
