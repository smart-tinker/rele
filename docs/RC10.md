# Rele 0.1.0-rc.10

В настройках связки, списка отправителей и автосоздания убрано вымышленное `@Rele`. Для вызова выберите через `@` настоящее имя подключённого агента в мессенджере. Slack распознаёт нативное упоминание по ID бота, Telegram — по username или ID; эта логика не менялась.

Кнопка «Изменить название только в Rele» открывает редактор локальной подписи выбранного источника. Название сохраняется в Rele; имена чата в мессенджере, агента и треда Codex не меняются. «Имя из мессенджера» сбрасывает локальную подпись.

Изменены только тексты интерфейса и документация. Права доступа, правила запуска, конфигурация подключений и схема SQLite v5 сохранены. Установку выполняет пользователь; живая приёмка Desktop, телефона, Slack Stop и spinner остаётся открытой.
