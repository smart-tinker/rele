# Rele 0.1.0-rc.25

Обновление Windows больше не пытается заменить byte-identical `runtime/node.exe`, который могут использовать инструменты Rele внутри общего Codex. Если runtime действительно изменился и прежний файл занят, установщик останавливает подготовку до замены файлов. Он не завершает Desktop, общий Codex или его MCP-процессы.

Подготовка остановки Gateway и резервной копии использует комплект самого установщика во временной папке. Она не импортирует установленный Engine/main и поэтому работает при отсутствующих модулях старой установки. Сохраняются проверки владельца, конкретного процесса Gateway, его задачи и защищённого локального API. Резервная копия SQLite включает WAL без запуска миграций; защищённый файл настроек копируется без изменения.

Временный Node и его дочерние процессы принадлежат только операции установщика. При её завершении они закрываются, временные файлы очищаются штатным механизмом Inno. При ошибке резервного копирования удаляется только новый незавершённый каталог; существующие резервные копии сохраняются.

Профиль Codex, исходные ID/история чатов, адрес подключения Desktop, настройки доступа и зависимости этой правкой не меняются. Функции вопросов Slack из [RC24](RC24.md) сохраняются. Установка не является отправкой нового запроса в Codex.

Результаты узких Windows-проверок и офлайн-сборок точного commit приводятся в GitHub release. Полная installer/OS-матрица для этой правки не повторяется; реальная доставка Slack/Telegram и работа с телефона остаются отдельной приёмкой.
