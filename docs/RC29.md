# RC29 — Codex 0.166 compatibility

Adds the exact Desktop backend version `0.166.0-alpha.5.1` to the shared
protocol allowlist. Automatic selection can choose it when installed; all
previous supported versions remain available. Adjacent and decorated version
strings remain unsupported.

No extra Codex installation is required. Profiles, conversations, Desktop
launch configuration and the controlled native update procedure are unchanged.
An already running older shared server is not replaced by reconnect alone.

The release notes bind the focused tests and real native check to the source
commit and artifact hashes. This change does not repeat the complete historical
installer, operating-system and messenger acceptance matrix.
