# 0.1.1-rc.16 — полный runtime Codex и alpha.6

Refs #81, #78. Цикл продолжает Windows-приёмку первого Stop после обновления Codex Desktop.

Rele сохраняет необходимые файлы выбранного Windows Codex в собственную рабочую копию.
Подготовка следующей версии не заменяет работающий сервер. Холодный запуск и
применение обновления проверяют сохранённые файлы, включая helpers и assets;
неполный или изменённый пакет не запускается. Профиль, авторизация, история,
адрес сервера и прежние запросы сохраняются отдельно от исполняемых файлов.

В матрицу совместимости добавлена точная версия Codex 0.166.0-alpha.6. Помимо
очереди и переподключения, изолированный сценарий проверяет custom `exec`, запуск
команды через `code-mode-host`, отмену и завершение очистки исходного хода.
Canonical CLI-пакет сохраняется со всеми объявленными файлами и assets.
Конверсия Desktop сохраняет пять файлов native runtime: main, code-mode-host,
command-runner, sandbox-setup и rg. Это не проверка GUI, voice или всех ресурсов
Desktop; её пригодность для команд alpha.6 подтверждается отдельным native gate.
Helpers разных версий не смешиваются.
Linux controlled updater остаётся ограничен проверенной alpha.5.1 и отвергает
кандидат alpha.6 до изменения процесса; подключение и протокол проверяются отдельно.

Source gates и native fixtures не заменяют приёмку готового приложения.
Commit, SHA256 пакетов и фактические результаты Windows/Linux приводятся в
описании RC после проверок. Windows Stop принимается только по новому сценарию
установленного приложения; старые запросы с неизвестным исходом не повторяются.
Stable, остальные машины и реальные мессенджеры в этот цикл не входят.
