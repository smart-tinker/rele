# Rele 0.1.0-rc.27

Страница Codex показывает работающую и установленную версии, предлагает
подготовить поддерживаемое обновление и применить его без перезагрузки Windows.
Настройки и подробная диагностика свёрнуты. Штатная рабочая копия Desktop
подписана корректно; отдельный CLI на Windows не требуется.

После подготовки завершите задачи и полностью выйдите из Desktop, CLI и других
клиентов общего Codex. В Rele подтвердите закрытие клиентов и нажмите
«Обновить Codex». Оставьте клиенты закрытыми до подтверждения. Rele сохраняет
новые входящие в очереди, проверяет общий простой и заменяет только свой точный
экземпляр сервера. После проверки версии, профиля и адреса очередь продолжается;
Desktop можно открыть обычным способом. UAC не требуется.

Работающий клиент или задача блокируют применение. Загруженный в памяти
завершённый чат сам по себе не считается выполняющейся задачей. Обновление
Rele, кнопки выбора backend и обновления статуса не меняют сервер автоматически.
Неподдерживаемая версия Desktop не предлагается для автоматического перехода.

Проверено на windows-test-host: настоящий production Engine/API Rele, подписанные backend
Desktop 0.164.0-alpha.11.1 → 0.165.0-alpha.1.2, прежние endpoint/home, ID,
архивность, контекст и очередь; отказы при клиенте/активной задаче; restart Rele
без повторной отправки. Использовался локальный fake provider и синтетические
разговоры. Native0.165 протокол отдельно проверен на Windows и Linux.

Реальные Desktop GUI, Slack/Telegram и весь installer/OS matrix этой итерацией
не перепроверялись. Независимые клиенты должны оставаться закрытыми на время
применения: штатного атомарного drain для этого WebSocket-сервера нет.
