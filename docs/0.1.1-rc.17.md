# 0.1.1-rc.17 — изображения Slack и финальные ответы

- [#84](https://github.com/smart-tinker/rele/issues/84): изображения из новых разрешённых запросов Slack передаются в тот же запрос Codex, в том числе без подписи. Пассивная история сохраняет метаданные вложений.
- [#87](https://github.com/smart-tinker/rele/issues/87): точные маркеры `NOREPLY` исключаются из финальных частей до склейки. Если итог состоит только из маркеров, Rele сохраняет штатную квитанцию подавления.
- Разрешения на приложения в Codex Desktop ([#83](https://github.com/smart-tinker/rele/issues/83)) и восстановление ранее импортированной истории ([#86](https://github.com/smart-tinker/rele/issues/86)) в этот кандидат не входят.

Очередь сохраняет сведения о новых вложениях в схеме базы v9. Для отката используйте резервную копию до обновления и штатный процесс восстановления. Не переотправляйте старые запросы с неизвестным исходом.
